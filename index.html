UI sound effects, performed live.

Comics had to draw the KA-CHUNK. Your buttons get to make it. Foley is a JavaScript library of 28 cues, synthesized with Web Audio the moment someone clicks, types, or toggles. No audio files, no dependencies.

Not your sound? Redraw it.

Four plain dials reshape any cue while you listen. Export a .wav or JSON, share it as a link, or apply it site-wide as a sound set your app loads in one line.

Install, add an attribute, bind. That's the job.

Foley ships as one ES module. Attributes cover the common cases, play() covers the rest, and the React and Vue bindings wrap the same core.

1

Install

$ npm install @foleyjs/core
2

Mark up and bind

<!-- one attribute per behavior -->
<button data-foley-press data-foley-release>Save</button>
<a data-foley-hover="tick">Docs</a>
<button data-foley-toggle>Dark mode</button>
<input data-foley-type="thock">
<!-- and things nobody clicked -->
<div data-foley-enter="bubble">Saved</div>
import { bind, observe, play, set } from "@foleyjs/core";

bind();                     // wires every data-foley-*
observe();                  // …and elements appearing or changing state
set({ volume: 0.7,          // 0 – 1
      transpose: 0,         // semitones, ±12
      space: 0.2,           // reverb send
      theme: "glass" });    // a name, or your sound set object

play("complete");           // any of the 28 cues
set({ theme: brandSet });   // load your identity from the designer
play("tick", { pitch: 4, volume: 0.3 });

const wav = await toWav("chime"); // Blob, rendered offline
3

In React or Vue

// npm install @foleyjs/react
import { useFoley } from "@foleyjs/react";

function App() {
  const { play } = useFoley({ volume: 0.7 });
  return <button onClick={() => play("success")}>
    Save
  </button>;
}
// npm install @foleyjs/vue
import { FoleyPlugin } from "@foleyjs/vue";
app.use(FoleyPlugin, { theme: "soft" });

<!-- then in any template -->
<button v-foley="'success'">Save</button>
<a v-foley:hover="'tick'">Docs</a>

Questions people actually ask.

The short answers. The docs have the long ones, and agents.md has the version for your coding agent.

Does Foley ship audio files?

No. Every cue is built at play time from Web Audio oscillators and filtered noise, so there is nothing to download, cache, or license.

How do I add a sound to a button?

Add an attribute such as data-foley-press and call bind() once at startup. It delegates from the root, so markup rendered later sounds too, and hover also fires on keyboard focus.

Will UI sounds annoy my users?

Foley is built not to. A master limiter caps loudness, a 60 ms cooldown stops repeats from stacking, pitch is humanized up to 30 cents, loops go quiet in background tabs, and set({ muted: true }) silences everything.

Does it work with React and Vue?

Yes. @foleyjs/react provides a useFoley() hook and @foleyjs/vue a plugin and a v-foley directive. Both wrap the same core, so cues and sound sets carry over.

Can I design my own sounds?

Yes. Cues are data. Edit one in the designer above or with getSpec() and playSpec(), then ship a sound set: your product's sonic identity as JSON.

Why does nothing play until I click?

Browsers block audio until a user gesture. bind() installs a one-time unlock listener, and play() resumes the audio context on its own.
